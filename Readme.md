# 🐍 Python Basics

Этот репозиторий содержит учебные примеры и небольшие программы на языке **Python**.  
Проект создан для изучения основ языка, практики синтаксиса и понимания базовой логики программирования.

Python — это высокоуровневый интерпретируемый язык программирования с простым и читаемым синтаксисом.  
Он широко используется в автоматизации, backend-разработке, data science, машинном обучении и скриптах.

В репозитории представлены примеры по следующим темам:
- ввод и вывод данных
- условные конструкции (`if / elif / else`)
- циклы (`for`, `while`)
- списки (`list`)
- кортежи (`tuple`)
- сортировка данных
- работа со строками
- базовые логические проверки

Проект носит учебный характер и может изменяться по мере изучения языка.

## ▶️ Запуск проекта

### 🪟 Windows

1. Установите Python с официального сайта:  
https://www.python.org/downloads/windows/

2. Проверьте установку:
```bash
python --version

```

### 🐧 Linux

1. Установите Python через менеджеров пакетов:

#### Ubuntu / Debian
``` 
sudo apt get update
sudo apt-get install python3
```
#### Arch Linux
```
sudo pacman -S python
```

2. Проверить установку:
```
python3 --version
```
